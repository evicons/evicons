title: Contributing
---

EVicons is a small, focused set: icons for e-mobility and EV charging only, no general UI icons and no brand or manufacturer logos. The maintainers draw every icon themselves, so that the whole set follows one [design guide](https://github.com/evicons/evicons/blob/main/docs/design-guide.md).

- **Need an icon?** Search the [gallery](/icons) first (English, German and French terms), then open an [icon request](https://github.com/evicons/evicons/issues/new?template=icon-request.yml) with the meaning, where you would use it and, for connectors, the standard. Please don't send icon files or pull requests with new drawings.
- **Found a problem?** Open a [bug report](https://github.com/evicons/evicons/issues/new?template=bug-report.yml) with the icon or package and the version.
- **Pull requests** are welcome for fixes to the packages, the build tools, the website and the documentation; see [CONTRIBUTING.md](https://github.com/evicons/evicons/blob/main/CONTRIBUTING.md).

All geometry is drawn from scratch; a test fails if an element is identical to one from Lucide. Changes for users go into the `Unreleased` section of the changelog.
